Інтерактивна шпаргалка (HTML & CSS)

1. Базові теги HTML

<h1 align="center">Заголовок</h1>

<p><a href="index.html">Посилання</a></p>

2. Способи підключення CSS

  • Inline (в тезі): <font style="font-size: 14pt; color: red;">Текст</font>
  • Embedded (в заголовку head): <style> .text1 { color: green; font-family: Arial; } </style>
  • External (зовнішній файл): <link rel="stylesheet" href="style.css">

3. Форматування шрифтів

p { font-style: italic; font-weight: bold; }
